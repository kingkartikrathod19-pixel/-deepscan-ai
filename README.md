# DeepScan AI — Source Code (reconstructed prototype)

This bundle is a reconstructed, single-file web prototype based on the project details previously discussed. It is **not guaranteed to be the exact source used to build the APK**.

## Files
- `index.html` — complete HTML, CSS and JavaScript source
- `README.md` — this file

## Run
Open `index.html` in a modern browser. It works without a server.

## Important implementation status
- Implemented: responsive UI, image file selection, preview, reset, demo result panel.
- Demo-only: output is selected from the filename (`cancer` -> illustrative 85, `medium` -> illustrative 50, otherwise illustrative 20).
- Not implemented: trained CNN, real image inference, clinically validated accuracy, real diagnosis, backend/database, hospital integration.
- The demo score is not a real model confidence score and must not be used for medical decisions.

To restore the exact code behind an existing APK, the original project source or original build folder is required.
